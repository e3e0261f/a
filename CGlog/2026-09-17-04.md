## 1. 問題與需求清單 (1-8 項)
1. **密鑰短碼長度優化**：將原本長度達 16/40 位的完整 GPG Key ID 自動截斷為精簡的 8 位短碼（例如 `FA9B204A`、`31C81A9D`），大幅提升終端顯示的整潔度。
2. **自動響應壓縮與寬度適配**：若當前環境未同步或所有 GPG 檔案皆無短碼時，系統會自動智慧壓縮（隱藏）短碼欄位，動態切換排版版型避免空間浪費。
3. **100% 絕對對齊排版**：採用精確的 Rust 格式化對齊語法（如 `{:<5}`, `{:<34}`, `{:<12}` 等），確保表格外框、標頭與各列資料 100% 垂直對齊。
4. **檔案大小單位精簡**：將原本較長的 `bytes` 單位簡化為清晰的 `B`（如 `81360 B`）。
5. **邊框外框優化**：縮短總寬度以完美適應標準終端機視窗，防止文字斷行或表格變形。
6. **極致響應速度保持**：維持 `a -l` 讀取本地快取記憶的秒開優勢，並支援 `a -l --sync` 深度同步更新。
7. **智慧防護與明文免識別**：非 `.gpg` 結尾檔案自動略過加密短碼，保持介面簡潔。
8. **沉澱歷史開發日誌**：依規定產出第 4 號日誌，確保 50 年後回溯開發脈絡清晰。

## 3. 更改文件大概邏輯與精簡代碼

### A. 密鑰短碼截斷與動態壓縮排版 (`src/main.rs`)
- **邏輯**：檢查是否有任何 GPG 檔案具備有效短碼 (`has_any_key`)。若有，顯示短碼欄位；若無，自動壓縮並隱藏短碼欄。同時將完整 Key ID 截斷為最後 8 位。
- **精簡代碼片段**：
```rust
// 智慧判斷是否需要展示短碼欄位
let mut has_any_key = false;
for filename in &file_names {
    if filename.ends_with(".gpg") {
        if let Some(entry) = ledger.records.iter().find(|r| r.file_name == filename) {
            if !entry.key_id.is_empty() && entry.key_id != "-" {
                has_any_key = true;
            }
        }
    }
}

// 提取 8 位短碼
let short_key = if key_id.len() > 8 && key_id != "-" {
    key_id[key_id.len() - 8..].to_string()
} else if key_id.is_empty() {
    "-".to_string()
} else {
    key_id
};
```

### B. 嚴格 100% 絕對對齊列印
- **邏輯**：利用 Rust `println!` 的寬度控制對齊符（如 `{:<5}`, `{:<34}`, `{:<12}`）與精確計算的橫線分隔符 (`{:-<5}`)，確保無論檔案名稱長短，表格欄位皆絕對垂直對齊。
- **精簡代碼片段**：
```rust
if has_any_key {
    println!("{:<5} {:<34} {:<12} {:<14} {:<42}", "編號", "檔案名稱", "短碼", "檔案狀態", "暴力破解推算時間 (目前最高級別)");
    println!("{:-<5} {:-<34} {:-<12} {:-<14} {:-<42}", "", "", "", "", "");
} else {
    println!("{:<5} {:<36} {:<16} {:<42}", "編號", "檔案名稱", "檔案狀態", "暴力破解推算時間 (目前最高級別)");
    println!("{:-<5} {:-<36} {:-<16} {:-<42}", "", "", "", "");
}
```
