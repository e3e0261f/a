# Cyber-NOte (a) 專案更新日誌 (編號 #03)
日期: 2026-09-17

## 1. 問題與需求清單 (1-8 項)
1. **`a -l` 快速響應優化**：預設執行 `a -l` 或 `a -k` 時，僅直接讀取本地化配置數據（`key_ledger.json`）與本地檔案狀態，絕不進行任何遠端 API 下載或動態密鑰識別，實現秒級快速響應。
2. **`a -l --sync` 專用同步命令**：新增 `--sync`、`-s` 旗標支援（如 `a -l --sync`），作為真正的遠端清單更新與 GPG 封包審計同步指令。
3. **雲端檔案智能補全與下載限制**：在 `sync` 模式下，優先利用本地持久化記憶，若本地無該檔案且需識別時，才自雲端 Gist 下載至臨時快取進行 `gpg --list-packets` 識別，並自動清除臨時檔。
4. **明文檔案免識別保護**：針對非 `.gpg` 結尾的明文 / 純文字檔案（如 `.asc`, `.txt`, `.note` 等），直接標記為明文，不進行 GPG Key ID 盲目識別或猜測。
5. **持久化記憶機制 (`key_ledger.json`)**：所有成功識別或同步的檔案短碼與加密狀態皆持久化存儲於配置目錄中，確保後續 `a -l` 無需重覆掃描。
6. **未識別短碼狀態空缺**：若檔案短碼尚未透過 `a -l --sync` 同步識別，列表直接保留空白，不隨便顯示「未知 / 未下載」等推測字串。
7. **複合命令解耦與效能提升**：徹底分離「快速檢索 (Fast Read)」與「深度鑑識同步 (Deep Sync)」，大幅提升 CLI 操作流暢度。
8. **更新日誌自動累加規範**：每次叠代精確產生帶有編號的 `.md` 日誌，便於 50 年後回顧與架構重構。

## 3. 更改文件大概邏輯與精簡代碼

### A. 快速響應與同步鑑識解耦 (`src/main.rs`)
- **邏輯**：將 `handle_list_and_ledger_command` 參數引入 `sync: bool`。當 `sync` 為 false 時，純粹讀取本地 `key_ledger.json` 快速印出表格；當 `sync` 為 true (`a -l --sync`) 時，才連線 Gist 掃描並對未識別的 `.gpg` 檔案進行條件式下載與 GPG 封包解析，並寫入持久化紀錄。
- **精簡代碼片段**：
```rust
fn handle_list_and_ledger_command(sync: bool, verbose: bool) {
    let note_dir = GameConfig::get_note_dir();
    let mut ledger = a::ledger::load_ledger();

    if sync {
        let token = get_github_token(verbose)?;
        if let Ok(files) = list_gist_files(&token, verbose) {
            for filename in files {
                let is_gpg = filename.ends_with(".gpg");
                let local_path = note_dir.join(&filename);
                let mut key_id = String::new();
                if !is_gpg {
                    key_id = "-".to_string();
                } else if let Some(existing) = ledger.records.iter().find(|r| r.file_name == filename && !r.key_id.is_empty()) {
                    key_id = existing.key_id.clone();
                } else if local_path.exists() {
                    key_id = a::ledger::extract_key_id_from_gpg_file(&local_path);
                } else {
                    // 萬不得已下載臨時快取識別
                    if let Ok(content) = fetch_from_gist(&filename, &token, false) {
                        let temp_path = note_dir.join(format!(".temp_inspect_{}", filename));
                        if fs::write(&temp_path, content.as_bytes()).is_ok() {
                            key_id = a::ledger::extract_key_id_from_gpg_file(&temp_path);
                            let _ = fs::remove_file(&temp_path);
                        }
                    }
                }
                let _ = a::ledger::record_ledger_entry(&filename, &local_path.to_string_lossy(), &key_id, "GPG_ENCRYPTED", 0, 1, &[], "Synced");
            }
            ledger = a::ledger::load_ledger();
        }
    }

    // 快速讀取本地 ledger 顯示表格
    for (idx, filename) in file_names.iter().enumerate() {
        let entry_opt = ledger.records.iter().find(|r| &r.file_name == filename);
        let key_id = entry_opt.map(|e| e.key_id.clone()).unwrap_or_default();
        println!("[{:<3}] {:<36} {:<24}", idx + 1, filename, key_id);
    }
}
```

### B. 命令分發與旗標傳遞 (`src/main.rs`)
- **邏輯**：攔截 `-l` / `-k` 命令時，透過 `args.iter().any(|a| a == "--sync" || a == "-s")` 判斷是否帶有同步旗標。
- **精簡代碼片段**：
```rust
if args.len() > 1 && (args[1] == "-l" || args[1] == "--list" || args[1] == "-k" || args[1] == "--ledger") {
    let sync = args.iter().any(|a| a == "--sync" || a == "-s" || a == "--update");
    handle_list_and_ledger_command(sync, verbose);
    return;
}
```
