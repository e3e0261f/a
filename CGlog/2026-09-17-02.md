# Cyber-NOte (a) 專案更新日誌 (編號 #02)
日期: 2026-09-17

## 1. 問題與需求清單 (1-8 項)
1. **Ledger 模組匯入修復**：修正 `src/main.rs` 中遺漏 `record_ledger_entry` 函式導致編譯失敗的問題。
2. **`a -e` 參數防呆提示**：單獨執行 `a -e` 時參數不足，需有明確的目標動作與用法提示。
3. **`a -ep` 與 `a -p` 語法調整**：新增 `a -ep` 作為 `a -e --pass` 的簡便寫法；廢止單獨使用 `a -p`，改為明確提示防呆。
4. **命令用法介面同步**：更新系統主 `a` 幫助選單，移除過時的 `a -ep` 提示，並對齊最新的加密指令。
5. **Change Log 規範建立**：將所有更新與代碼改動存入專案目錄 `CGlog/`，使用日期加編號作為 `.md` 檔名。
6. **`a -l` 與 `a -k` 功能合併**：將遠端 Gist 清單查詢與本地金鑰審計鑑識合併為統一中心。
7. **遠端 Gist 封包智能鑑識**：針對未下載至本地的遠端 `.gpg` 檔案，自動快取下載並執行 `gpg --list-packets` 提取 Key ID 與評估暴力破解時間。
8. **智慧編號刪除與衝突解決**：`a --delete` 支援編號（如 `a --delete 1`）與檔名刪除，並解決純數字檔名與編號的衝突。

### B. 雲端清單與金鑰審計合併鑑識 (`src/main.rs`)
- **邏輯**：透過 `list_gist_files` 獲取遠端檔案清單，逐一檢查本地或透過臨時快取下載遠端 `.gpg` 檔案，呼叫 `extract_key_id_from_gpg_file` 獲取 Key ID，並計算破解時間。
- **精簡代碼片段**：
```rust
fn handle_list_and_ledger_command(verbose: bool) {
    let token = get_github_token(verbose)?;
    let files = list_gist_files(&token, verbose)?;
    for (idx, filename) in files.iter().enumerate() {
        // 若本地不存在，從遠端 fetch 寫入暫存檔以解析 GPG Packet
        let key_id = a::ledger::extract_key_id_from_gpg_file(&temp_path);
        println!("[{}] {} - Key ID: {}", idx + 1, filename, key_id);
    }
}
```

### C. 智慧編號刪除 (`src/main.rs`)
- **邏輯**：允許使用者輸入編號（如 `1`）刪除遠端 Gist 檔案，系統自動將編號轉換為對應檔名。
- **精簡代碼片段**：
```rust
let mut filename_to_delete = target.clone();
if !files.contains(target) {
    if let Ok(idx) = target.parse::<usize>() {
        if idx > 0 && idx <= files.len() {
            filename_to_delete = files[idx - 1].clone();
        }
    }
}
delete_gist_file(&filename_to_delete, &token, verbose);
```
