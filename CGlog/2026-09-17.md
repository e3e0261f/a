# Cyber-NOte (a) 專案更新日誌與代碼改動記錄
日期: 2026-09-17
作者: Google AI Studio Coding Agent

## 1. TOTP 雙重認證加密與管理功能
- **加密本地存儲**：TOTP 金鑰數據與標籤現已改為透過 GPG 進行加密，存儲於 `note_dir/totp_secrets.json.gpg`。透過 `a -s` 可自動同步至雲端 Gist。
- **安全性列表展示**：`a -t` 與 `a -t --list` 改為列出編號與標籤（如 `[1] google`），不再明文暴露 6 位數即時驗證碼。
- **彈性新增語法**：支援 `a -t --add google --code "..."` 以及 `a -t --add --name google --code "..."`。

## 2. 檔案加密核心重構與 `-e` / `-ep` 參數包裝
- **包裝進 `-e` 參數**：
  - `a -e <檔案>`：使用預設 GPG 公鑰進行本地加密落盤。
  - `a -e --pass <密碼> <檔案>`：使用 S2K 對稱密碼防窮舉加固加密。
  - `a -ep <密碼> <檔案>`：`a -e --pass` 的快捷簡便寫法。
  - `a -e --id <key_id> <檔案>`：支援指定非預設金鑰 ID 進行加密。
  - **嚴格無上傳約束**：未加 `-s` 參數時，所有加密動作純粹在本地落盤，絕不進行任何雲端上傳。
  - **`a -s` 不加 `-e`**：預設以明文/原樣推送至 Gist。
- **防呆設計**：單獨使用 `-p` 已被廢止並提供防呆提示，避免迷茫誤觸。

## 3. 金鑰審計與 GPG 封包解析 (`a -k` / `--ledger`)
- 執行 `a -k` 或 `a --ledger` 時，會自動掃描本地 `.gpg` 檔案，並呼叫 `gpg --list-packets` 深度解析 GPG 封包，精準萃取並顯示每個加密檔案的實際金鑰 ID 短碼。

## 4. 解密與下載組合參數
- 支援 `-xd`、`-dx`、`-x -d`、`-d -x` 組合參數，實現自雲端下載並自動解密還原。

## 5. 網頁管理端 (`a -w`) 同步
- `server.ts` 後端 API 完整支援各項加密、解密、TOTP 與金鑰審計介面，確保 CLI 與 Web UI 達到 100% 功能同步。
