# Cyber-NOte 開發日誌 #17 (2026-09-19)

## 🚀 批量多參數輸入與 `--all` 全功能聯動升級

### 💡 核心改進亮點
1. **全命令多參數/批量操作支援**：
   - 擴展 `a --delete` / `a -delete` / `a -del` / `a --rm` / `a -rm` 支援多檔案、多編號批量刪除（例如：`a --delete 2021homelee.gpg 123.gpg DAO.note.gpg`）。
   - 擴展 `a -e` / `--encrypt` 及 `a -x` / `--decrypt` 支援一次傳入多個檔案路徑進行批量加密與解密。
2. **`--all` / `-a` 萬能組合威力全開**：
   - `a -e --all`：一鍵掃描並批量加密本地未加密的所有筆記檔案。
   - `a -x --all`：一鍵解密本地目錄中所有的 `.gpg` 密文檔案。
   - `a -s --all`：一鍵批量推送同步本地所有筆記至雲端 Gist。
   - `a --delete --all`：一鍵批量刪除雲端 Gist 倉庫中的全部遠端檔案。
3. **零錯誤編譯與嚴格類型防護**：
   - 通過 `compile_applet` (Rust build) 與 `lint_applet` (TypeScript) 雙重驗證。
