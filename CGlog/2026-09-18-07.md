## 3. 更改文件大概邏輯與精簡代碼

### A. 精確進位單位格式化邏輯 (`src/main.rs`)
- **邏輯**：實現 1 位整數 + 1 位小數、大於等於 10 即進位的精確單位轉換函式。
- **精簡代碼片段**：
```rust
let format_size = |bytes: u64| -> String {
    let b = bytes as f64;
    if b < 10.0 {
        format!("{:.1}b", b)
    } else if b < 10.0 * 1024.0 {
        format!("{:.1}k", b / 1024.0)
    } else if b < 10.0 * 1024.0 * 1024.0 {
        format!("{:.1}m", b / (1024.0 * 1024.0))
    } else {
        format!("{:.1}g", b / (1024.0 * 1024.0 * 1024.0))
    }
};
```
